## [1.0.0] - 2026-08-19

### Added

- Initial release of DocumentScanner SDK umbrella repository
- Multi-platform architecture with submodules
- Android SDK with CameraX integration
- iOS SDK with AVFoundation
- Web SDK with WebRTC
- macOS SDK structure
- Windows SDK placeholder (in development)
- Linux SDK placeholder (in development)
- Flutter plugin for cross-platform support
- Comprehensive documentation
- Architecture guides
- Workflow rules
- Repository setup guides
