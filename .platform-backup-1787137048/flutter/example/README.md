# DocScanner SDK Example

Example Flutter app demonstrating how to use the doc_scanner_sdk plugin.

## Features Demonstrated

- Request camera permissions
- Scan single document side
- Scan both sides of a document
- Display scanned images
- Error handling

## Getting Started

1. Run the example:
   ```bash
   flutter run
   ```

2. Grant camera permissions when prompted

3. Tap "Scan Single Side" to scan one side of a document

4. Tap "Scan Both Sides" to scan front and back
